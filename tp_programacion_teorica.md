1. ¿Qué tipo de dato es el más adecuado para almacenar la edad de una
persona?
a) String
b) Boolean
c) Integer (Entero)
d) Float (Flotante)

La respuesta es la c.

2. ¿Cuál de los siguientes valores representa un tipo de dato Booleano?
a) "verdadero"
b) true
c) 1
d) 'T'

LA respuesta es la b

3. ¿Qué tipo de dato usarías para almacenar el precio de un producto con
decimales?
a) Integer
b) Float/Double
c) Char
d) Array

La respuesta es la b

4. Si necesitas almacenar una sola letra (como 'A', 'b', '1'), ¿cuál es el tipo de
dato correcto?
a) String
b) Integer
c) Char (Caracter)
d) Boolean

La respuesta es la c

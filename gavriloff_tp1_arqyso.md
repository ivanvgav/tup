# Desarrollo
## Primera parte
### Primera consigna
Siguiendo a Murdocca y Heuring la arquitectura de computadoras permite mostrar
las características visibles para el programador que determinan el
*comportamiento funcional* del sistema al ejecutar programas. Esto permite que
se pueda analizar desde niveles de abstracción altos o bajos: desde como el
usuario interactúa con programas al nivel más bajo o como ser los componentes
electrónicos básicos de la computadora como el transistor o los circuitos.

Por otro lado, Stallings considera que la arquitectura de las computadoras es la
encargada de ver los atributos de un sistema visible para el programador y que
tengan una relación directa en la ejecución de un programa. Por ello para él la
arquitectura de computadoras tendrá que ver con el conjunto de instrucciones,
cómo se entran y salen las instrucciones, qué tipo de datos usa el sistema y los
modos en los que lo procesa.

### Segunda consigna
- CPU: Es el encargado de controlar y coordinar todas las instrucciones que
  realiza el sistema
- Memoria: Almacena datos e instrucciones que utiliza el CPU durante la
  ejecución de los programas
- Dispositivos de entrada: Son aquellos dispositivos que permiten ingresar
  información o datos al sistema.
- Dispositivo de salida: Son aquellos dispositivos que permiten mostrar la
  información y los resultados de los programas

### Tercera consigna
Tanto la unidad de control como la unidad lógico aritmética son parte de la CPU.
  - Unidad de control: Lleva el control de cada una de las instrucciones
  - ALU: Unidad lógico-aritmética: Es el encargado de realizar las operaciones
    matemáticas y lógicos

### Cuarta consigna
La diferencia entre memoria RAM y ROM es que la primera solo almacena
información e instrucción de manera temporaria, cada vez que la computadora se
apaga, la RAM se limpia. Mientras que la memoria ROM posee ciertas instrucciones
que solo puede ser leídas pero no modificadas o borradas. Es una memoria de solo
lectura. Respecto del almacenamiento secundario este es tiene la capacidad de
guardar y hacer persistir la información y datos sin importar que la computadora
este encendida o no. A su vez puede modificarse, borrarse y editarse en
contraposición con la ROM.

### Quinta consigna
La memoria es fundamental para la ejecución de un programa debido a que la CPU
por si sola no puede llevar a cabo todo lo necesario para que se ejecute el
mismo. La CPU necesita de un elemento donde pueda ir guardando información,
datos e instrucciones que sean requeridas por el programa. La memoria cumple ese
rol: sea memoria RAM la cual se encuentra de manera cercana y de rápido acceso a
la CPU, sea el almacenamiento secundario que permite guardar de manera
persistente la información requerida por el programa o los datos necesarios para
llevar a cabo una tarea.
